# DS9 Reader

Minimal, lightweight, multiplatform EPUB reader with **Calibre Content Server** sync.

## Goals

- Feel like a Kindle for your self-hosted Calibre library
- Fast local reading (EPUB)
- Download books from Calibre
- Sync reading progress back to Calibre
- Run on **Android, iOS, Desktop, and WasmJS**

## Stack

- Kotlin Multiplatform + Compose Multiplatform
- **Koin** DI
- **Arrow** (`Either`) error handling
- **SQLDelight** local library/progress store
- **Ktor** Calibre HTTP client
- Pure-Kotlin EPUB parser (shared across targets)

## Features

### Library
- Local library grid
- Continue reading row
- Progress bars
- Download state

### Calibre
- Configure Content Server URL + optional basic auth
- Sync book metadata from `/ajax/books`
- Download EPUB via `/get/EPUB/<id>`
- Push/pull last-read position via Calibre book position endpoints

### Reader (Kindle-like)
- Chapter pagination via prev/next + tap zones
- Center tap toggles controls
- Table of contents
- Font size slider
- Auto-save progress
- Background progress sync to Calibre

## Project layout

```text
composeApp/
  src/
    commonMain/     # domain, calibre client, epub parser, UI
    androidMain/    # Android driver/storage
    desktopMain/    # JVM driver/storage
    nativeMain/     # iOS driver/storage
    wasmJsMain/     # browser driver/storage
```

## Calibre setup

1. In Calibre: **Preferences → Sharing over the net**
2. Start Content Server
3. Prefer basic auth for remote use:
   ```bash
   calibre-server --enable-auth --auth-mode=basic
   ```
4. In DS9 Reader settings, set:
   - Server URL: `http://<host>:8080`
   - Username/password if enabled
   - Device name: `DS9-Reader`

## Run

### Desktop
```bash
./gradlew :composeApp:run
```

### Android
```bash
./gradlew :composeApp:installDebug
```

### WasmJS
```bash
./gradlew :composeApp:wasmJsBrowserDevelopmentRun
```

### iOS
Open the Xcode project generated by the KMP iOS framework target, or use your existing iOS app wrapper with the `ComposeApp` framework.

## Architecture notes

- **Source of truth for library metadata**: Calibre
- **Source of truth for on-device reading UX**: local SQLDelight DB + local EPUB files
- Progress is marked dirty on page changes and pushed to Calibre
- Web build stores downloaded EPUBs in browser storage (demo-scale). Desktop/Android/iOS store files on disk.
